# Fictional product, honest presentation

"iPhone Duo" is a concept, not a shipped Apple product. We render it with the
requested name but label the project clearly as an independent concept study and
include a non-affiliation disclaimer in the page and README. We do not copy iOS
assets, use real prices, or provide fake purchase links. This preserves the
creative brief without misleading a viewer, and it means all screen artwork must
be original — which is also why the displays use the invented Duo OS.
